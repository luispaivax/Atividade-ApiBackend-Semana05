# Atividade-ApiBackend-Semana05

A estrutura de pastas foi organizada para separar as responsabilidades da aplicação, facilitando a manutenção, a compreensão e a evolução do projeto. A pasta `models` concentra as entidades do banco de dados, `repositories` é responsável pelo acesso e manipulação dos dados, `services` concentra as regras de negócio, `routes` define os endpoints da API e recebe as requisições HTTP, enquanto `infrastructure` reúne configurações relacionadas à infraestrutura, como a conexão com o banco de dados. Essa organização segue princípios de separação de responsabilidades e conceitos de Clean Architecture, tornando o código mais organizado e facilitando futuras alterações.

## Instalar as dependencias
`pip install -r requirements.txt`
